
# Kim's Game

A browser-based memory training game focused on attention,
observation, and recall.

## Features

- 10 difficulty levels
- Player setup and configurable session length
- Word-card memorisation interface
- Missing-word selection interface
- Score and accuracy summary
- Welcome and instructions modal
- Responsive layout

Some features are still under development.

## Technology Stack

- React
- JavaScript
- HTML5
- CSS3
- Vite
- localStorage

## Prerequisites

- Node.js LTS
- npm

## Installation

Clone the repository and open the project directory.

Install dependencies:

npm install

Start the development server:

npm run dev

## Production Build

npm run build

Preview the production build:

npm run preview
